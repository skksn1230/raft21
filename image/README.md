### MCUのはんだ付け
３つの角を仮止め（図はピンヘッダを１つ折って使用している）して、もう１つの角をはんだ付けします。
![MCU1](MCU1.jpg)
１つの角（図では右下）をはんだ付けできたら、同様にほかの角もはんだ付けします。
![MCU2](MCU2.jpg)
４つの角だけはんだ付けできた状態。
![MCU3](MCU3.jpg)
四隅からちょっとずつはんだ付けしていきます。
![MCU4](MCU4.jpg)
すべてはんだ付けできた状態。
